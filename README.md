# Ledger System

## Features

- Double-entry accounting
- Transaction processing
- Balance snapshots
- Multi-currency support
- Audit trail
- Reporting
- Data archival
- Migration framework
- Integration tests

## Tech Stack

- Node.js
- TypeScript
- PostgreSQL
- Redis
- Kafka
- RabbitMQ
- Docker

## Run

```bash
npm install
docker compose up -d
npm test
npm start
```
